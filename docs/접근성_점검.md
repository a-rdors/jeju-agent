# 화면 접근성 자동 점검 (Lighthouse)

실행: 2026-11-20 03:04 · 도구: Lighthouse 12.2.1(`npx lighthouse`, Chrome headless) · 대상: https://jeju-gachi.vercel.app (배포된 첫 화면)

| 기기 설정 | 접근성 | 권장사항(Best Practices) |
|---|---|---|
| 휴대폰(기본 설정) | **100** | 100 |
| PC(`--preset=desktop`) | **100** | 100 |

점검 명령:

```bash
npx lighthouse https://jeju-gachi.vercel.app --only-categories=accessibility,best-practices --chrome-flags="--headless=new"
npx lighthouse https://jeju-gachi.vercel.app --only-categories=accessibility,best-practices --preset=desktop --chrome-flags="--headless=new"
```

## 점수에 들어가지 않는 실험 항목에서 찾은 것

- `label-content-name-mismatch`(보이는 글자와 화면 읽기 이름이 다름): 지도 위 지역 이름표 15개. 화면에는 "애월 16곳"이 보이는데 화면 읽기 이름은 "애월 나들이 장소 16곳. 누르면 펼쳐져요"라서, 음성으로 "애월 16곳"이라고 말해 누르는 기능(음성 제어)이 이름표를 못 찾을 수 있다.
- 고침: 화면 읽기 이름을 보이는 글자로 시작하게 바꿨다(`web/components/KakaoMap.tsx`, 예: "애월 16곳. 애월 나들이 장소, 누르면 펼쳐져요").
- 위 점수는 고치기 전 배포본에서 잰 것이다. 이 항목은 점수 계산에 들어가지 않아 점수는 그대로다.

## 자동 점검이 보지 못하는 것

- Lighthouse는 첫 화면만 보고, 대화·추천 결과·일정표 화면은 보지 않는다.
- 화면 읽기 프로그램(TalkBack, VoiceOver)으로 실제로 써 보는 점검, 실제 이동약자 사용자 테스트는 하지 않았다.
