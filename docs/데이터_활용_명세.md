# 데이터 활용 명세 — 제주 같이나들이

제주 AI·빅데이터 활용 AI Agent 개발 챌린지 최종 결과물. 수치는 저장소의 정제 결과(`data/processed`) 기준이며 2026-11-19에 집계했다.

## 3. 이용조건과 출처 표기

| 대상 | 이용조건 | 우리가 지킨 것 |
|---|---|---|
| 제주데이터허브 데이터(1~8번) | 제주데이터허브 이용약관과 각 데이터 상세 페이지의 이용조건 | 화면 카드와 문서에 출처·기준일 표기. OpenAPI는 본인 프로젝트 키로 호출하고 키는 저장소에 넣지 않음 |
| 공공데이터포털 데이터·API | 공공데이터포털에 표시된 데이터별 이용허락범위 | 출처 표기, 서비스 키는 `.env`로만 관리 |
| 카카오 API·지도 | 카카오 개발자 서비스 이용약관(호출 한도) | 키는 `.env`로만 관리, 지도 화면에 카카오 표기 유지 |
| Open-Meteo | 데이터 CC BY 4.0, 비상업 무료 이용 | 출처 표기(화면 날씨 카드, README) |
| 장소 사진 | 제주데이터허브 무장애여행 일반정보에 들어 있는 사진 | 사진 크게 보기 화면에 "사진: 제주데이터허브 무장애여행 정보" 표기 |
| 비짓제주 지역 구분 | 지역 이름과 나누는 법만 참고 | 글·사진·데이터는 가져오지 않음 |
| OpenStreetMap 길 모양 | ODbL 1.0(출처 표기), 공개 길찾기 서버 이용 정책(가벼운 사용) | 선 모양만 씀(판정·거리에는 쓰지 않음). 코스 탭에 "지도의 코스 선 모양: © OpenStreetMap 기여자" 표기. 서버는 실행 중에 부르지 않고 미리 한 번(1초 간격)만 받음 |
| 개인정보 | 사용하지 않음 | 사용 데이터는 모두 장소·시설 단위 공공 정보. 사용자의 현재 위치는 '내 위치' 단추를 누르고 브라우저에서 동의할 때만 받아 그 대화 요청에만 쓰고, 서버에 저장하지 않음. '내 일정'은 로그인 없이 이 브라우저(localStorage)에만 저장하고, 일정표를 내려받을 때만 담은 곳 목록을 서버에 보내며 서버는 저장하지 않음 |

API 키는 코드와 제출물 어디에도 넣지 않았다. 발급과 설정 방법은 `.env.example`과 README 1장에 있다.

## 4. 전처리와 분석 흐름

다시 만들 때는 아래 순서로 돌린다. 앞 단계가 만든 파일을 뒤 단계가 읽기 때문이다.

1. `scripts/01_download_mujangae.py` — 제주데이터허브 공개 무장애 파일 150개
2. `scripts/02_build_access_table.py` — `points.csv`, `places.csv`, `nearby.csv`, `companion.csv`
3. `scripts/06_fetch_external.py` — 관광공사 무장애 API(`tour_places.csv`), 화장실 주소 → 좌표(`toilets.csv`)
4. `scripts/03_build_support.py` — `tour_places.csv`를 읽어 `places_app.csv` 등을 만듦
5. `scripts/06_fetch_external.py contacts` — `places_app.csv`를 읽어 장소 전화번호(`place_contacts.csv`)
6. `scripts/06_place_photos.py`(`places_app.csv`를 읽어 사진·주소), `scripts/07_hub_api.py`(버스 정류소, 약국 영업 상태) — 순서 상관없음
7. `scripts/08_route_paths.py` — 코스 지점을 읽어 지도 코스 선 모양(`route_paths.json`). 없어도 화면은 돌아간다(지점을 직선으로 이음)


### 경사 기준
「장애인·노인·임산부 등의 편의증진 보장에 관한 법률 시행규칙」 별표 1의 접근로 기울기(18분의 1 이하, 부득이하면 12분의 1)를 각도로 바꾸면 약 3.2°, 4.8°다. 정제 표에는 이 법정 기준 등급도 남겼다. 다만 경사 기록이 있는 54곳 중 53곳이 기준을 넘어 장소끼리 비교가 되지 않았다. 그래서 화면 판정에는 상대 단계를 쓰고, "갈 수 있다"는 보장이 아니라고 함께 표시한다.

### 추출 정확도 검수
무작위 표본을 원문과 대조했다. 회차마다 새 표본을 썼다(`docs/추출_검수기록.md`).
- 2021 조사 50곳: 60개씩 3회, 95.0% → 93.3% → 96.7%
- 2020 조사 20곳: 40개씩 2회, 87.5% → 97.5%
- 1차 대조는 개발 중 AI 보조(Claude)가 했다. 사람 검수는 아직 하지 않았다. 팀원이 볼 확인표(`docs/사람검수_표본.md`)는 만들어 두었지만 칸이 비어 있다.
