# 사용자 매뉴얼 — 제주 같이나들이

휠체어·유모차·어르신·임산부와 함께하는 제주 나들이를 준비할 때 쓰는 화면 사용법과, 문제가 생겼을 때의 대처법이다.
설치·실행 절차는 `README.md` 1장, 환경변수는 `.env.example`에 있다.

---

## 1. 여는 방법

| 방법 | 주소 | 필요한 것 |
|---|---|---|
| 배포 주소(설치 없음) | https://jeju-gachi.vercel.app | 인터넷, 브라우저(크롬·엣지·사파리) |
| 내 PC에서 실행 | http://localhost:3000 | README 1장대로 API 서버와 웹 화면을 켠다 |

PC와 휴대폰 모두 같은 화면을 쓴다. 휴대폰에서는 지도 위에 아래쪽 패널이 올라온다.

## 2. 화면 구성

```
┌──────────────────────────────────────────────┬──────────────────┐
│ [이름표] [큰 글씨] [패널] [처음으로]             │  오른쪽 대시보드  │
│ 지도 범례                                      │  ─ 한눈에        │
│                                              │  ─ 코스          │
│              전체 화면 지도                    │  ─ 식당          │
│   (추천 장소 점·코스·식당·병원 표식)              │  ─ 병원·약국     │
│ [내 위치]                                     │                  │
│                                [하르방 도우미] │                  │
└──────────────────────────────────────────────┴──────────────────┘
```

- **지도**: 추천 장소, 코스 지점(주의 지점은 빨강), 화장실·쉼터, 식당·병원·약국 표식. 확대·축소 단추가 있고, 섬 전체를 볼 때는 장소 점이 숫자 묶음으로 보인다.
- **오른쪽 대시보드**(휴대폰은 아래 패널): 탭 4개 `한눈에 · 코스 · 식당 · 병원·약국`.
- **하르방 도우미**: 대화창. 평소 말투로 물어보면 된다.
- **위쪽 단추**: `큰 글씨`(글자를 크게), 패널 열기·닫기, `처음으로`(처음 화면으로).
- **내 위치**: 누르면 브라우저가 위치 권한을 묻는다. 허용하면 "내 근처" 기준으로 찾는다.

## 3. 사용 순서

**① 누구와 가는지 고른다.** 처음 화면의 단추 4개 중 하나를 누른다.

| 단추 | 기준 |
|---|---|
| 휠체어 타는 가족 | 턱 없는 입구, 장애인 화장실 |
| 아기와 유모차 | 계단 없는 길, 수유실 |
| 걷기 힘든 어르신 | 짧고 완만한 길, 쉴 곳 |
| 임신 중인 가족 | 평평한 길, 가까운 병원 |

단추 대신 대화창에 "아빠가 휠체어 타셔"처럼 말해도 된다. 처음 화면에서 `어디쯤 가세요?`(제주시, 애월·한림 등)를 고르면 그 동네에서 찾는다. 고르지 않으면 제주 전체에서 찾는다.

**② 추천을 본다.** `한눈에` 탭에 1순위 장소가 나온다.
- 판정(갈 만해요 / 동행인 도움이 있으면 갈 만해요 / 확인이 더 필요해요)과 한 줄 이유
- 판정을 누르면 **근거가 된 조사 지점 원문과 기준일**
- 현장 사진(있는 장소만). 사진을 누르면 크게 보이고, 화살표로 넘긴다
- 시설 정보 확인표, 조심할 점, 비 오면 대신 갈 곳
- `길안내`(카카오맵), `전화`(관리기관), `자세히`

`본 곳 빼고 새로 찾기`를 누르면 이미 본 곳을 빼고 다시 찾는다.

**③ 코스를 본다.** `코스` 탭과 지도에서 코스 지점을 따라가며 경사·턱·계단 위치를 확인한다. 빨간 점이 주의 지점이다.

**④ 식당을 찾는다.** `식당` 탭이나 대화로 찾는다. 예: "근처에 밥 먹을 데", "할머니가 이가 안 좋으셔".
- 1층 가게를 먼저 보여 주고, 휠체어 진입이 확인된 가게에는 표시가 붙는다.
- 식사 조건(씹기 편한, 속 편한, 안 매운, 해산물 없는, 싱거운, 아이 메뉴, 날음식 피하기)은 말한 것만 적용한다.
- 추천 이유는 업종·가게 이름으로 **추정**한 것이다. `확인할 점`을 전화로 물어보자.

**⑤ 비상 정보를 본다.** `병원·약국` 탭에서 가까운 약국(폐업 제외), 병·의원, 응급실, 장애인 화장실, 버스 정류소와 직선거리를 볼 수 있다. 응급 상황에는 119에 먼저 연락한다.

**⑥ 일정을 짠다.** "반나절 일정 짜 줘"라고 하면 장소 → 식당 → (원하면) 카페 순서로 묶어 준다. 답 아래 `일정표 내려받기`를 누르면 한 장짜리 일정표(HTML)가 저장된다. 브라우저로 열어 인쇄하거나 PDF로 저장한다. 일정표에는 장소별 확인표, 가까운 장애인 화장실, 급할 때 연락처, 가기 전 전화로 확인할 것이 들어 있다. 여러 날 일정은 첫 나들이만 제안하고, 다른 날은 동네를 말하면 하나씩 다시 찾는다.

## 4. 이렇게 물어보면 된다

| 하고 싶은 것 | 예시 |
|---|---|
| 장소 추천 | "아빠가 휠체어 타시는데 주말에 바다 보러 갈 만한 데 있어?" |
| 동네 지정 | "유모차 끌고 애월 쪽 산책하고 싶어" |
| 날씨 반영 | "비 오는 날 전동 휠체어로 갈 만한 실내 있을까", "내일 바람 많이 불면 해안길 괜찮을까?" |
| 특정 장소 | "사려니숲 휠체어로 갈 수 있어?" |
| 식당 | "할머니가 이가 안 좋으셔서 갈 식당", "함덕 근처 흑돼지 집", "성산에서 횟집 갔다가 카페도" |
| 비상 정보 | "거기 근처 약국", "가까운 장애인 화장실" |
| 기준 위치 | "공항에서 가까운 곳", "내 근처" |
| 일정 | "반나절 일정 짜 줘" |

숫자(경사 몇 도, 몇 km)는 말하지 않아도 된다. 누구와 가는지를 전혀 알 수 없을 때만 버튼으로 한 번 되묻는다.

**하지 않는 것**: 예약·결제, 맛 순위, 의학적 판단, 숙소 추천, 제주 밖 장소. 이런 질문에는 못 하는 이유와 대신 할 수 있는 것을 알려 준다.

## 5. 오류와 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| 답변 앞에 "(AI 연결이 안 돼서 기본 모드로 찾았어요)" | OpenAI 키가 없거나, 잘못됐거나, 연결이 안 됨 | `.env`의 `OPENAI_API_KEY` 확인. 기본 모드도 저장된 데이터로 장소를 추천한다(대화 해석은 단어 기반) |
| 지도가 카카오맵이 아니라 기본 지도로 나옴 | `KAKAO_JS_KEY`가 없거나 도메인이 등록되지 않음 | 카카오 개발자 앱 > 플랫폼 > Web에 `http://localhost:3000`(또는 배포 주소)을 등록하고, 카카오맵 사용 설정을 켠다 |
| 지도가 안 뜨거나 키 오류 | `127.0.0.1:3000`으로 열었음 | `http://localhost:3000`으로 연다(등록한 도메인과 같아야 함) |
| 화면은 뜨는데 추천·대화가 안 됨 | API 서버(8000)가 꺼져 있음 | 터미널 1에서 `.venv\Scripts\python -m uvicorn server.api:app --port 8000` 실행. http://localhost:8000/api/config 가 열리면 정상 |
| `Address already in use` / 포트 사용 중 | 8000 또는 3000을 다른 프로그램이 씀 | 그 프로그램을 끄거나 다른 포트로 실행. API 포트를 바꾸면 웹 화면 실행 전에 `API_ORIGIN=http://localhost:<포트>`를 설정한다 |
| `npm install` 실패 | Node.js 버전이 낮음 | Node.js 20 이상 설치 후 다시 실행 |
| `pip install` 실패 / `python` 없음 | Python 3.11 미만이거나 PATH 없음 | Python 3.11 이상 설치, 설치 화면에서 "Add to PATH" 선택 |
| PowerShell에서 가상환경 실행 막힘 | 실행 정책 | 위 명령처럼 `.venv\Scripts\python`을 직접 부르면 활성화 없이 된다 |
| 식당·병원 전화번호가 비어 있음 | `KAKAO_REST_KEY` 없음 | 키를 넣으면 전화번호가 나온다. 없어도 나머지는 동작 |
| 대화 답이 늦음(10초 이상) | AI가 도구를 여러 번 부름(최대 6회) | 잠시 기다린다. 프록시 제한은 120초 |
| "위치를 가져오지 못했어요" | 위치 권한 거부, 또는 기기가 위치를 못 줌 | 브라우저 주소창의 권한에서 위치 허용, 또는 동네 이름을 말한다 |
| 내 위치를 눌러도 제주 전체가 보임 | 현재 위치가 제주 밖 | 정상 동작. 제주 밖 위치는 쓰지 않는다 |
| 사진 칸이 없는 장소가 있음 | 사진 자료가 있는 곳은 코스 장소 70곳 중 50곳 | 정상 동작 |
| `scripts/07_hub_api.py`: ".env 에 JEJU_PROJECT_KEY 가 없어요." | 허브 프로젝트 키 없음 | `.env.example` 안내대로 발급. 화면 실행에는 필요 없다(저장된 CSV 사용) |
| `scripts/06_place_photos.py`가 olefile·PIL 오류 | 선택 라이브러리 미설치 | `.venv\Scripts\python -m pip install olefile Pillow` |

## 6. 제약사항

- **데이터 기준일**: 무장애 현장 정보는 2020~2021년 조사 자료다. 지금과 다를 수 있으니 방문 전에 전화로 확인한다. 화면 카드에 기준일이 표시된다.
- **판정은 보장이 아니다**: "갈 만해요"는 조사 자료로 본 비교 판단이다. "안전하다"는 뜻이 아니다.
- **"확인 안 됨"**: 자료에 없는 항목이다. 시설이 없다는 뜻이 아니다. 답의 `확인할 점`이나 일정표의 '가기 전 전화로 확인할 것'을 보고 전화로 물어보자.
- **거리는 직선거리**다. 휠체어 기준 길찾기 경로와 이동 시간은 제공하지 않는다. `길안내`는 일반 카카오맵 경로다.
- **버스 정류소**는 위치만 안내한다. 저상버스 운행·노선은 확인하지 않는다.
- **식당**: 메뉴, 좌식·입식, 엘리베이터 자료가 없다. 식사 조건은 추정이다.
- **인터넷 필요**: AI 대화(OpenAI), 지도(카카오), 날씨(Open-Meteo)는 인터넷이 있어야 한다. 장소 데이터는 저장된 CSV를 쓴다.
- **AI 답변은 매번 조금씩 다를 수 있다.** 장소 후보와 판정은 코드가 계산하므로 같은 조건이면 같다.
