# 제주 같이나들이 디자인 시스템

화면은 **지도가 주인공**이고, 패널과 단추는 지도 위에 조용히 떠 있는다. 꾸밈을 더하기 전에 바탕색 차이와 여백으로 먼저 정리한다.

- 색과 글꼴은 제주 팔레트와 Pretendard를 그대로 쓴다.
- 짜임(글자 단계, 간격, 둥글기, 깊이, 움직임)은 Apple 웹사이트의 원칙을 가져왔다.
- 모든 값은 [app/globals.css](app/globals.css) 맨 위 `:root` 토큰에 있다. **색·크기·둥글기·그림자를 직접 적지 말고 토큰을 쓴다.**

## 1. 색

### 팔레트

| 토큰 | 값 | 뜻 |
|---|---|---|
| `--gyul` | #F0892B | 귤색. **누르는 것(행동)에 쓰는 유일한 강조색** |
| `--gyul-hover` / `--gyul-soft` / `--gyul-tint` | #E07A1C / #FDE9D6 / #FFF8EE | 귤색 눌림·옅은 바탕 |
| `--gyul-text` | #9C4A07 | 흰 바탕 위 귤색 글자, 보조 단추 글자, 초점 테두리 |
| `--on-gyul` | #2A1606 | 귤색 바탕 위 글자(대비 4.5:1 이상) |
| `--leaf` 계열 | #2F7A4D … | 감귤잎 초록: '갈 만해요', 나들이 장소 점 |
| `--sea` 계열 | #2C6EA6 … | 제주 바다 파랑: '도움이 있으면 갈 만해요', 날씨·안내 |
| `--red` 계열 | #B83227 … | 조심할 곳, 응급 |
| `--basalt` / `--slate` | #2E3135 / #5E6368 | 현무암: 대화창 머리 / 회색 판정 |

### 바탕·글자·선

| 토큰 | 쓰는 곳 |
|---|---|
| `--card` (#FFF) | 기본 바탕 |
| `--paper` (#F5F5F1) | 한 단 다른 바탕. **테두리 대신 이 바탕색 차이로 구역을 나눈다** |
| `--pearl` | paper 위에서도 단추로 보여야 하는 아주 옅은 바탕 |
| `--hairline` (검정 8%) | 카드·패널의 1px 테두리 |
| `--divider` (검정 6%) | 목록 줄 사이 선 |
| `--stone-2` | 누를 수 있는 칩·입력창의 테두리(hairline보다 진함) |
| `--ink` / `--muted` / `--faint` | 본문 / 보조 글 / 출처·입력 안내 |

### 뜻(상태) 색

판정과 안내에만 쓴다. 바탕(`-bg`)과 글자(`-fg`)를 짝으로 쓴다.

| 토큰 짝 | 뜻 |
|---|---|
| `--ok-bg` / `--ok-fg` | 가능, 있음 |
| `--warn-bg` / `--warn-fg` | 조심 |
| `--info-bg` / `--info-fg` | 날씨, 안내 |
| `--danger-bg` / `--danger-fg` | 응급 |
| `--neutral-bg` / `--neutral-fg` | 참고, 확인 안 됨 |

### 지도 색

카카오 지도 위 표식은 JS로 그리므로 [lib/mapData.ts](lib/mapData.ts)에 같은 값을 따로 둔다. 둘 중 하나를 바꾸면 다른 쪽도 함께 바꾼다.

| 종류 | 색 |
|---|---|
| 추천 장소 | 판정 색: 초록 · 파랑 · `--slate` |
| 코스 | `--map-route` |
| 화장실 | `--map-toilet` |
| 식당 | `--map-food` |
| 병원·약국 | `--map-help` |
| 조심할 곳 | `--red` |

### 규칙

- 누르는 것은 언제나 귤색 하나로 표시한다. 초록·파랑을 단추 색으로 쓰지 않는다.
- 꾸밈용 그라데이션은 쓰지 않는다. 현무암도 무늬 없이 단색이다.
- 시설 목록처럼 여러 줄이 나란히 있을 때는 줄마다 색을 칠하지 않는다. 아이콘은 회색으로 두고, 있는 것은 글자를 진하게, 없는 것은 흐리게 한다.

## 2. 글자

글꼴은 `--font` (Pretendard)이다. 기준은 17px(`html` 106.25%)이고, 큰 글씨 모드는 모두 125%로 커진다.

| 토큰 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `--fs-display` | 28px | 600 | 첫 화면 제목, 빈 대화창 질문 |
| `--fs-title` | 24px | 600 | 장소 이름 |
| `--fs-tagline` | 21px | 600 | 소제목, 판정 |
| `--fs-body` | 17px | 400 | 본문, 단추 |
| `--fs-callout` | 16px | 400 | 촘촘한 목록, 말풍선, 안내 줄 |
| `--fs-caption` | 14px | 400 | 보조 글, 칩, 탭, 작은 단추 |
| `--fs-fine` | 12px | 400 | 출처, 꼬리표 |
| `--fs-micro` | 10px | 400 | 휴대폰 상단 도구 이름 **만** |

- **굵기는 400 · 600 · 700 세 가지뿐이다.** 500과 800은 쓰지 않는다. 제목은 600, 700은 아주 드물게(목록 앞 동그라미 기호 정도) 쓴다.
- 제목은 자간을 조인다(`--ls-display` -0.02em). 본문은 -0.01em, 14px 이하는 거의 0으로 둔다.
- 줄 간격: 본문 1.5(`--lh-body`), 제목 1.22. 한글은 받침이 있어 Apple(1.07~1.19)보다 조금 넉넉하게 잡았다.

## 3. 간격

8을 기준으로 한다. `md`는 본문 크기(17px)에 맞췄다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sp-xxs` | 4px | 글자와 꼬리표 사이 |
| `--sp-xs` | 8px | 목록 항목 사이, 단추 사이 |
| `--sp-sm` | 12px | 패널 안 덩어리 사이, 안내 줄 안쪽 |
| `--sp-md` | 17px | 카드 안쪽, 휴대폰 시트 좌우 |
| `--sp-lg` | 24px | PC 패널 안쪽, 소제목 위 |
| `--sp-xl` / `--sp-xxl` | 32 / 48px | 큰 구역 사이 |

2px, 6px, 10px 같은 값은 글자 줄맞춤 같은 미세 조정에만 쓴다.

## 4. 둥글기

**알약 모양은 '누르는 것'의 표시다.**

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--r-xs` | 5px | 꼬리표(`.tag`, `.pill`) |
| `--r-sm` | 8px | 도구 단추(`.tool`, `.tb-btn`), 판정 알약 |
| `--r-md` | 11px | 안내 줄 상자, 목록 단추(`.mp-btn`), 확대·축소 |
| `--r-lg` | 18px | 카드, 떠 있는 패널·대화창 |
| `--r-pill` | 9999px | 주·보조 단추, 칩(동네·후보), 탭, 입력창, 지도 묶음 |
| `--r-full` | 50% | 하르방 얼굴, 번호, 지도 점 |

중간값(12, 14, 16, 20px …)은 만들지 않는다.

## 5. 깊이

| 단계 | 처리 | 쓰는 곳 |
|---|---|---|
| 평평함 | 그림자·테두리 없음, 바탕색 차이 | 안내 줄, 접힌 칸, 타일, 질문지 |
| 얇은 선 | 1px `--hairline` | 카드, 대화 말풍선, 표 |
| 반투명 흐림 | `--glass` + `--blur` | 상단 막대, 범례, 찾는 중 표시, 확대·축소, 대시보드 |
| 떠 있음 | `--shadow-float` | 지도 위에 뜬 것: 대시보드, 대화창, 하르방 단추, 지도 카드·말풍선 |

**그림자는 `--shadow-float` 하나뿐이다.** 카드, 단추, 글자에는 그림자를 넣지 않는다. 예외는 `--shadow-marker` 하나인데, 지도 표식이 지도 그림 위에서 보이게 하는 데만 쓴다.

## 6. 움직임

- 누르면 살짝 작아진다. 단추·칩·탭은 `--press` (0.95배), 폭이 넓은 줄 단추는 `--press-wide` (0.98배).
- 시간은 `--dur-fast` (0.15s)와 `--dur` (0.25s), 곡선은 `--ease`를 쓴다.
- 둥둥 떠다니는 장식 움직임은 쓰지 않는다. 기다림 점 세 개도 회색으로 깜빡이기만 한다.
- `prefers-reduced-motion`에서는 움직임을 모두 끈다.

## 7. 부품

**단추**에는 두 가지 문법이 있다.

| 부품 | 모양 | 쓰는 곳 |
|---|---|---|
| `.btn-primary` | 귤색 알약, 글자 `--on-gyul` 600 | 한 화면에 하나 있는 핵심 행동(찾기, 길안내) |
| `.btn-secondary` | 투명 바탕, 귤색 1px 테두리, 글자 `--gyul-text` | 둘째 행동(전화, 코스, 지도) |
| `.btn-tertiary` | 글자만 `--gyul-text` | 돌아가기 같은 글자 링크 |
| `.tool`, `.tb-btn` | `--r-sm` 네모 | 큰 글씨·패널 숨김·닫기 같은 화면 설정 |

**칩**(`.wchip` 동네, `.cand` 후보)

- 흰 알약에 `--stone-2` 테두리를 두른다.
- 고르면 귤색 2px 테두리가 된다(테두리 1px + 안쪽 1px). 바탕은 칠하지 않는다.

**탭**(`.tabs`)

- `--paper` 알약 안에 나눔 단추를 넣는다.
- 고른 탭은 흰 바탕에 600 굵기로 표시한다.

**카드**(`.card`, `.choice-card`, `.checks`, `.evidence`, `.expander`)

- 흰 바탕, `--hairline`, `--r-lg`로 만들고 안쪽 여백은 `--sp-md`다.
- 고른 카드는 귤색 2px 테두리로 표시한다.

**안내 줄**(`.line`, `.ans-row`, `.info`, `.weather`, `.busline`, `.where-note`, `.more-d`)

- 테두리 없이 뜻 색 바탕에 `--r-md`를 쓴다.
- 앞에 18px 아이콘을 둔다.

**입력창**(`.chatform`)

- 흰 알약에 `--stone-2` 테두리를 두른다. 초점이 가면 귤색 2px이 된다.
- 보내기 단추는 귤색 동그라미다.

**지도 조작 단추**(`.locate`, `.km-zoom`)

- 지도 앱처럼 왼쪽 아래에 모았다. 44px 크기, 반투명 흐림 바탕, `--r-md`.
- PC는 내 위치 단추가 확대·축소 단추 바로 위에 있다. 휴대폰은 시트 윗변 왼쪽(하르방 단추 맞은편)을 따라 움직인다.
- 내 위치를 쓰는 중이면 아이콘이 파랗게 바뀌고, 지도에 파란 점(`.km-me`)이 뜬다.
- 위치를 못 받았거나 제주 밖이면 단추 옆에 안내가 4.5초 동안 떴다 사라진다.

**아이콘**

- [lib/icons.ts](lib/icons.ts)의 경로(Material 채움, 몇 개는 선 그림)를 `<Icon name>`으로 그린다.
- 지도 표식도 같은 경로를 흰색으로 그린다.
- **화면에 이모지를 쓰지 않는다.** 필요한 그림이 없으면 `lib/icons.ts`에 24×24 경로를 더한다.

## 8. 화면 폭

| 폭 | 배치 |
|---|---|
| 640px 이상 | 오른쪽 위에 대시보드(420px)가 뜨고, 대화창은 같은 자리에 겹친다 |
| 640px 이상, 높이 780px 이하 | 첫 화면 그림을 빼고 여백을 `--sp-md`로 줄인다 |
| 640px 이상, 높이 700px 이하 | 글자·단추 높이를 한 단 더 줄인다 |
| 640px 미만 | 아래에서 끌어올리는 시트가 되고, 대화창은 화면 전체를 쓴다 |

누르는 곳의 높이:

| 대상 | 높이 |
|---|---|
| 지도 조작 단추(내 위치, 확대·축소), 하르방 단추 | 44px 이상 |
| 패널 안 단추 | 38px (작은 단추 36px) |
| 칩·탭 | 34px |

패널 안 단추는 옆 단추와 8px 이상 띄워서, 누르는 범위가 겹치지 않게 한다.

패널과 대화 기록은 스크롤은 되지만 스크롤 막대는 보이지 않는다.

## 9. 하지 말 것

- 토큰 밖의 색(16진수)·크기·둥글기·그림자를 CSS나 TSX에 직접 쓰기
- 귤색 말고 다른 색으로 단추 만들기
- 카드·단추에 그림자 넣기, 꾸밈용 그라데이션 쓰기
- 굵기 500·800 쓰기, 본문을 16px보다 작게 쓰기(출처·꼬리표 제외)
- 이모지를 아이콘 대신 쓰기
- 상태 바탕을 줄마다 다른 색으로 칠해 무지개처럼 만들기
