# 제주 같이나들이 제출 문서

제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품작 「제주 같이나들이」의 제출 문서다.
문서마다 md 원본과, 바로 열어 볼 수 있는 PDF를 함께 넣었다.
모든 제출 문서를 한 파일로 합친 PDF(표지·목차·책갈피 포함)는 `제주같이나들이_제출문서.pdf`다.

- 바로 써보기: https://jeju-gachi.vercel.app (PC·휴대폰 같은 주소)
- 실행 소스 코드: 저장소의 `app/`(Agent·Prompt·도구), `server/`(API), `web/`(화면), `scripts/`(데이터 처리·테스트)

| 폴더 | 구분 | 파일 |
|---|---|---|
| `1_AI_Agent_기획서` | AI Agent 기획서 | `기획서.pdf` (원본 `기획서.html`) |
| `2_실행환경_매뉴얼` | 실행환경·매뉴얼 | `README`(설치·실행·의존성), `.env.example`(환경변수 예시), `사용자_매뉴얼`(사용법·오류 대처·제약사항) |
| `3_데이터_활용_명세` | 데이터 활용 명세 | `데이터_활용_명세`(사용 데이터·출처·이용조건·전처리 흐름·오픈소스 목록·AI 사용 내역) |
| `4_결과_설명자료` | 결과 설명자료 | `결과_설명자료`(문제 정의·Agent 구조·주요 기능·실행 결과·검증·한계·센터 활용 방안) |
| `5_검증_기록` | 검증 기록 | `추출_검수기록`, `사람검수_표본`, `테스트_기록`, `시나리오_테스트`, `시나리오_확인테스트`, `폭넓은_질문_테스트`, `새질문_테스트`, `접근성_점검`, `대규모_시뮬레이션`(데이터·도구 전수 점검 + 조합 질문 199개), `결과_원자료/`(테스트 실행 결과 JSON) |
| `6_데모_영상` | 데모 영상 | `제주_같이나들이_데모.mp4`(2분 33초, 1600×900, 자막 포함) |

문서 안에서 `docs/○○.md`처럼 적힌 곳은 저장소 안의 위치다. 같은 이름의 파일이 위 폴더에 들어 있다.

API 키는 제출물에 넣지 않았다. 발급·설정 방법은 `2_실행환경_매뉴얼/.env.example`에 있다.
